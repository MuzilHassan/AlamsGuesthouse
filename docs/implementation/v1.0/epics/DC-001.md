# DC-001 — Poly-X Authentication and Authorization Middleware

Provides the Poly-X token introspection middleware that protects every admin dashboard route. It verifies the Poly-X access token, checks the admin role grant, enforces organization-id matching, and fails closed with 401/403/503. This component exists because REQ-FUNC-001, REQ-FUNC-002, REQ-FUNC-003, and REQ-NFUNC-003 require authenticated admin sessions with MFA and fail-closed behaviour, and the TAD mandates Poly-X for identity rather than building authentication.
