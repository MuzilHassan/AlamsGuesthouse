# DC-002 — Content Data Store

Provides the PostgreSQL database schema and Prisma ORM layer that persists all managed content (rooms, room images, promotions, hero images, gallery images, blog posts). This component exists because REQ-FUNC-020 and REQ-NFUNC-006 require content to persist across restarts and deployments, and the TAD selects PostgreSQL 16 managed with Prisma 6.
