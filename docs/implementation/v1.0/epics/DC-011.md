# DC-011 — Admin Dashboard Shell and Accessibility

Provides the admin dashboard layout shell, navigation, and accessibility conformance across all admin dashboard screens. This component exists because REQ-NFUNC-005 requires the admin dashboard to conform to WCAG 2.2 AA, and a consistent shell with navigation, header, and Poly-X UserButton ties the dashboard sections together.
