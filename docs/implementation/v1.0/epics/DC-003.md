# DC-003 — Cloudinary Image Upload Service

Provides the image upload endpoint that sends images from the admin dashboard to Cloudinary and returns the Cloudinary URL for storage in the data store. This component exists because REQ-FUNC-010 requires all dashboard images to be uploaded to Cloudinary with the returned URL stored as the image reference, and the TAD mandates Cloudinary.
