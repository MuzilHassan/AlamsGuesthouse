# DC-012 — Notification Dispatcher

Provides the notification dispatcher unit that calls Poly-X poly-alert for email and in-app notifications when content events occur. This component exists because the scope constraints mandate Poly-X for notifications rather than building a product-owned mailer, and the TAD (TAD-006) selects poly-alert. Which content events trigger notifications is an open question.
