# DC-006 — Promotion Management

Provides admin dashboard UI and API endpoints for creating, editing, and removing promotions associated with rooms, and for displaying active promotions on the public site. This component exists because REQ-FUNC-012, REQ-FUNC-013, REQ-FUNC-014, and REQ-FUNC-015 require promotion management through the dashboard and public display of active promotions.
