# DC-010 — Static Content Migration

Provides the migration script that reads existing static content from data/rooms.ts, data/hero.ts, data/gallery.ts, and related files and writes it into PostgreSQL as initial content. This component exists because REQ-FUNC-021 requires existing static content to be migrated to the data store as initial content, and the TAD specifies a migration script with an idempotent upsert approach.
