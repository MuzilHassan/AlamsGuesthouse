# DC-004 — Room Listing Management

Provides admin dashboard UI and API endpoints for creating, editing, and deleting room listings with name, description, amenities, images, maximum occupancy, and price. This component exists because REQ-FUNC-004, REQ-FUNC-005, REQ-FUNC-006, and REQ-FUNC-011 require full CRUD on room listings and price updates through the dashboard.
