# DC-001-03 — Token introspection and admin role enforcement middleware

Express middleware using @poly-x/sdk requireUser() or polyx.auth.introspect(token) on every /api/admin/* request. Checks the admin role in permissions.modulePermissions. Returns 401 unauthenticated, 403 no admin role or organization-id mismatch, 503 Poly-X unreachable. Introspection timeout of 5 seconds. Results cached briefly keyed by user, session, permVersion.

**Contract:** polyx.auth.introspect(bearerToken) -> { active, userId, organizationId, sessionId, permissions }; check admin role in permissions.modulePermissions; 401 inactive token | 403 missing admin role or org-id mismatch | 503 Poly-X unreachable within 5s timeout; cache keyed by user+session+permVersion, max-age 60s

## Why

REQ-FUNC-001, REQ-FUNC-003, REQ-NFUNC-002, and REQ-NFUNC-003 require that every admin API request is verified against Poly-X introspection, the admin role grant is checked, organization-id matching is enforced, and the system fails closed with 401, 403, or 503. This middleware is the authoritative authorization gate for all /api/admin/* routes.

## What

An Express middleware using @poly-x/sdk introspects the Poly-X access token on every /api/admin/* request, checks the admin role in permissions.modulePermissions, enforces organization-id header matching, caches results briefly keyed by user+session+permVersion, and returns 401 for an inactive token, 403 for a missing admin role or org-id mismatch, and 503 within 5 seconds when Poly-X is unreachable.

## Scope

**In:** The token introspection middleware, admin role check, organization-id mismatch check, fail-closed 503 handling with 5s timeout, and introspection result caching keyed by user+session+permVersion with max-age 60s.

**Out:** BFF catch-all route (DC-001-01), edge gate middleware (DC-001-02), sign-in page UI (DC-001-04), account lifecycle pages (DC-001-05), and notification dispatch (separate component via Poly-X poly-alert). Poly-X provides token verification; no local JWT validation, JWKS endpoint, or password store is built here.

## Acceptance

- Given an unauthenticated request to any admin dashboard route, When the system checks the Poly-X session, Then the system returns HTTP 401 and does not display the dashboard
- Given an authenticated request whose Poly-X token lacks the admin role, When the system checks the role grant, Then the system returns HTTP 403 and does not display the dashboard
- Given an authenticated request with the admin role, When the system checks the Poly-X session, Then the system grants access to the admin dashboard
- Given a request to an admin dashboard route, When the Poly-X auth service is unreachable, Then the system returns HTTP 503 and does not grant access to the dashboard
- Given Poly-X is unreachable, When a site visitor loads the public website, Then the public site continues serving existing content from the data store
- Given a request to an admin dashboard route and the Poly-X auth service unreachable, When 5 seconds elapse, Then the system returns HTTP 503
- Given a request to an admin dashboard operation with a Poly-X token that does not have the admin role, When the system introspects the token, Then the system returns HTTP 403
- Given a request to an admin dashboard operation with no Poly-X token, When the system introspects the token, Then the system returns HTTP 401
