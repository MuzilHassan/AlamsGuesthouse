# DC-002-02 — RoomImage table

Prisma schema for RoomImage table storing Cloudinary URLs and display positions for room listing images.

**Contract:** RoomImage { id UUID PK, room_id UUID FK->Room not null, cloudinary_url text not null, display_position int not null }

## Why

REQ-FUNC-020 and REQ-NFUNC-006 require room listing images to persist across restarts and deployments alongside their parent room records.

## What

A RoomImage table in PostgreSQL 16 with a foreign key to Room, defined via a Prisma 6 schema with migration and rollback, storing Cloudinary URLs and display positions for room images.

## Scope

**In:** The Prisma model and migration for the RoomImage table only: columns id (UUID PK), room_id (UUID FK to Room, not null), cloudinary_url (text not null), display_position (int not null), and the FK relation to Room.

**Out:** The Room table itself (DC-002-01); the Prisma client configuration (DC-002-07); any image upload logic or Cloudinary integration; API endpoints that serve room images.

## Tasks

- [ ] **T1** — Add the RoomImage model to prisma/schema.prisma with id as @id @db.Uuid, room_id as UUID not null with a @relation to Room, cloudinary_url as String not null, display_position as Int not null, and the corresponding relation field on Room _(verify: prisma validate succeeds and the RoomImage model has the FK relation to Room with onDelete behaviour specified)_
- [ ] **T2** — Generate the Prisma migration for the RoomImage table (prisma migrate dev --name add_room_image_table) and verify the up SQL creates the room_image table with the FK constraint to room(id) _(verify: the migration SQL creates room_image with id uuid PK, room_id uuid not null referencing room(id), cloudinary_url text not null, display_position int not null, and a FK constraint)_
- [ ] **T3** — Write the down migration that drops the room_image table, so the migration is reversible _(verify: running the down migration removes the room_image table and its FK constraint cleanly)_
- [ ] **T4** — Write a unit test that inserts a Room, inserts a RoomImage referencing it, simulates a restart by re-instantiating the PrismaClient, and reads the RoomImage back to confirm it is present and unchanged with the correct room_id _(verify: the test creates a room and a linked room_image, re-instantiates the client, reads the room_image and confirms cloudinary_url and display_position match and room_id resolves to the parent room; TC-031 is demonstrated)_
- [ ] **T5** — Definition of Done: run prisma validate, apply the migration and its rollback, and run the persistence test suite for RoomImage _(verify: prisma validate passes, the room_image migration applies and rolls back without error, the persistence test passes confirming room image content survives a simulated restart, and the schema is committed)_
