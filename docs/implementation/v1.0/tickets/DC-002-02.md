# DC-002-02 — RoomImage table

Prisma schema for RoomImage table storing Cloudinary URLs and display positions for room listing images.

**Contract:** RoomImage { id UUID PK, room_id UUID FK->Room not null, cloudinary_url text not null, display_position int not null }

## Why

REQ-FUNC-020 and REQ-NFUNC-006 require room listing images to persist across restarts and deployments; the RoomImage table stores Cloudinary URLs and display positions for each room's images.

## What

A Prisma model and PostgreSQL migration for the RoomImage table with id (UUID PK), room_id (FK to Room, not null), cloudinary_url (text not null), and display_position (int not null), plus its rollback migration.

## Scope

**In:** The RoomImage Prisma model definition, its foreign key to Room, and its up/down SQL migration only.

**Out:** The Room table itself (DC-002-01); the Prisma client generation and DATABASE_URL configuration (DC-002-07); any image upload or Cloudinary integration logic; any API endpoints that read or write room images.

## Tasks

- [ ] **T1** — Add the RoomImage model to prisma/schema.prisma with id as UUID @id @default(uuid()), room_id as UUID with a @@relation to Room (onDelete cascade), cloudinary_url as non-null String, display_position as non-null Int, and a @@index on room_id _(verify: prisma validate succeeds; the RoomImage model has id UUID PK, room_id UUID FK->Room not null, cloudinary_url text not null, display_position int not null, and the relation to Room is declared)_
- [ ] **T2** — Generate and apply the Prisma migration for the RoomImage table with npx prisma migrate dev --name add_room_image_table, and confirm the down migration drops the RoomImage table cleanly _(verify: the migration creates a room_image table with columns id, room_id, cloudinary_url, display_position and a foreign key constraint on room_id referencing room(id); prisma migrate down removes the room_image table and its foreign key without errors)_
- [ ] **T3** — Write a persistence test that inserts a Room row and a linked RoomImage row, restarts the Prisma client connection, and re-reads both rows to confirm they survive a connection cycle _(verify: after closing and reopening the Prisma client, the inserted RoomImage row is present with room_id, cloudinary_url, and display_position unchanged and the foreign key to Room is intact, satisfying TC-031 for the RoomImage table)_
- [ ] **T4** — Definition of Done: run prisma validate, run the migration up and down, run the persistence test, and confirm the schema is committed _(verify: prisma validate passes, migrate up creates the room_image table with the contract columns and FK to room, migrate down removes it cleanly, the persistence test passes with no data loss across a connection restart, and the migration file is committed to the repository)_
