# DC-006-05 — Active promotions public display

Logic within the public content endpoint that filters promotions where is_active is true and includes them with their associated room data for public site display.

**Contract:** Public content query includes promotions where is_active = true, joined to Room; removed or inactive promotions excluded from public response

## Why

Site visitors need to see active promotions for rooms on the public site so that current special offers are visible, satisfying REQ-FUNC-015.

## What

A query within the public content endpoint that filters promotions where is_active is true, joins them to their associated Room data, and excludes removed or inactive promotions from the public response.

## Scope

**In:** The active-promotions filter logic in the public content query, the Prisma join to Room, and the exclusion of inactive or removed promotions.

**Out:** Does not build the admin promotion CRUD endpoints (DC-006-01, DC-006-02, DC-006-03) or the admin promotions UI (DC-006-04). Does not alter the Room model or the public content endpoint's existing room-listing structure beyond adding the active promotions inclusion.

## Tasks

- [ ] **T1** — Implement the active-promotions query in the public content endpoint: filter promotions where is_active = true, join to Room via roomId, and include the promotion data (title, description) in the room response payload for rooms that have an active promotion _(verify: GET /api/content/rooms returns rooms with their active promotions included (title and description) in the response; rooms without an active promotion have no promotion field or an empty promotions array)_
- [ ] **T2** — Ensure removed promotions (deleted via DC-006-03) and inactive promotions (isActive = false) are excluded from the public content response _(verify: a room whose promotion was deleted does not show that promotion in GET /api/content/rooms; a room whose promotion has isActive = false does not show that promotion in GET /api/content/rooms)_
- [ ] **T3** — Write integration tests covering TC-025: GET /api/content/rooms includes the active promotion for Room A and no promotion for Room B (whose promotion was removed); only promotions where is_active is true appear _(verify: TC-025 passes: GET /api/content/rooms includes the active promotion for Room A with its title and description; no promotion appears for Room B; no promotion with is_active = false appears in the response)_
- [ ] **T4** — Definition of Done: all tests pass, TC-025 is demonstrated, and the query is deployed to the test environment _(verify: the integration test suite passes including TC-025; GET /api/content/rooms in the test environment includes only active promotions joined to their rooms)_

## Acceptance

- Given a room with an active promotion stored in the data store, When a site visitor loads the room listing on the public site, Then the public site displays the promotion for that room
- Given a room whose promotion has been removed, When a site visitor loads the room listing on the public site, Then the public site does not display a promotion for that room
