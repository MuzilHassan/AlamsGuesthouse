# DC-007-02 — PUT /api/admin/gallery/:id

Edit gallery image caption and alt text.

**Contract:** PUT /api/admin/gallery/:id { caption?, altText? } -> 200 { galleryImage } | 401 | 403 | 404 | 422 | 503

## Why

REQ-FUNC-017 requires that an admin can edit the caption and alt text of an existing gallery image, so the displayed gallery content stays accurate and up to date.

## What

A PUT /api/admin/gallery/:id endpoint that accepts optional caption and alt text updates, updates the gallery image record, and returns 200 with the updated object.

## Scope

**In:** The PUT /api/admin/gallery/:id route handler, Prisma update call, 404 handling for a non-existent id, Poly-X introspection and admin role authorization, and error responses (401, 403, 404, 422, 503).

**Out:** The Prisma schema and GalleryImage model (provided by DC-002-07), the Poly-X SDK and introspection middleware (provided by DC-001-03), the POST and DELETE gallery endpoints (DC-007-01, DC-007-03), the gallery management UI (DC-007-04), and the public gallery content API.

## Tasks

- [ ] **T1** — Scaffold the PUT /api/admin/gallery/:id route handler, wiring the Poly-X introspection middleware from DC-001-03 (requireUser) to authenticate the caller, check the admin grant in permissions.modulePermissions, and validate the organization-id header against the token's organizationId _(verify: a request without a Bearer token receives 401; a request with a valid token but no admin grant receives 403; a request with a mismatched organization-id header receives 403; a request when Poly-X is unreachable receives 503)_
- [ ] **T2** — Implement the PUT handler body: find the gallery image by id from the route param (return 404 if not found), update the caption and altText fields from the request body, and return 200 with the updated galleryImage object _(verify: PUT /api/admin/gallery/:id with caption 'Poolside view' and altText 'Poolside view from room balcony' on an existing image returns 200 with the updated galleryImage object where caption is 'Poolside view' and altText is 'Poolside view from room balcony'; PUT on a non-existent id returns 404)_
