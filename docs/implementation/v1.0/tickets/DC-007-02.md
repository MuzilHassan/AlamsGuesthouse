# DC-007-02 — PUT /api/admin/gallery/:id

Edit gallery image caption and alt text.

**Contract:** PUT /api/admin/gallery/:id { caption?, altText? } -> 200 { galleryImage } | 401 | 403 | 404 | 422 | 503

## Why

REQ-FUNC-017 requires that an admin can edit the caption and alt text of an existing gallery image, so that image descriptions stay accurate and accessible.

## What

PUT /api/admin/gallery/:id accepts optional caption and altText, updates the matching gallery_images row, and returns 200 with the updated galleryImage object.

## Scope

**In:** The PUT /api/admin/gallery/:id route handler, its request validation, the Prisma update on the gallery_images table, the Poly-X introspection middleware wiring, and the structured log with request id.

**Out:** Does not build the gallery management UI (DC-007-04), the POST or DELETE endpoints (DC-007-01, DC-007-03), the image upload (DC-003-01), or any authentication or session handling (Poly-X provides it).

## Tasks

- [ ] **T1** — Scaffold the PUT /api/admin/gallery/:id route handler that validates the id path parameter as a valid identifier and validates the body for optional caption (string) and altText (string), returning 422 with a field-specific error code for an invalid id format _(verify: PUT /api/admin/gallery/invalid-id with a valid body returns 422 with code INVALID_ID_FORMAT; PUT with a valid id and body passes validation to the handler logic)_
- [ ] **T2** — Wire the Poly-X introspection middleware from DC-001-03 before the handler: introspect the Bearer token, check the admin role in permissions.modulePermissions, validate the organization-id header against the token's organizationId, and fail closed with 401 for an inactive token, 403 for a missing admin role or org-id mismatch, and 503 when Poly-X is unreachable within the 5s timeout _(verify: a request with an expired token returns 401 with shouldRelogin true; a request with a valid token but no admin role returns 403; a request with a mismatched organization-id header returns 403; when Poly-X is unreachable the endpoint returns 503 within 5s)_
- [ ] **T3** — Implement the handler logic that finds the gallery_images row by id via the Prisma client, returns 404 with code GALLERY_IMAGE_NOT_FOUND when no row exists, and otherwise updates caption and altText and returns 200 with the updated galleryImage object _(verify: PUT /api/admin/gallery/{existingId} with caption 'Poolside view' and altText 'Poolside view from room balcony' returns 200 with the galleryImage object where caption is 'Poolside view' and altText is 'Poolside view from room balcony'; PUT with a non-existent id returns 404 with code GALLERY_IMAGE_NOT_FOUND)_
- [ ] **T4** — Add structured logging with the request id, user id, and action 'gallery_image_update' on success, 404, and error paths, and add a unit test and an integration test covering TC-027 (success), 404 not found, 422 validation, 401 unauthenticated, 403 forbidden, and 503 Poly-X unreachable _(verify: the integration test for TC-027 asserts 200 with the updated galleryImage object where caption is 'Poolside view' and altText is 'Poolside view from room balcony'; the 404, 422, 401, 403, and 503 test cases each assert the correct status and error code; structured logs include the request id on all paths)_
- [ ] **T5** — Definition of Done: run the full test suite, confirm the endpoint is registered in the API route documentation, and confirm the endpoint is deployed to the test environment _(verify: all tests pass; the OpenAPI spec lists PUT /api/admin/gallery/:id with its 200, 401, 403, 404, 422, and 503 responses; the endpoint responds on the test environment)_
