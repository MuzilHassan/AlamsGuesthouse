# DC-003-01 — POST /api/admin/upload

Admin endpoint that accepts a multipart image file, sends it to Cloudinary via the cloudinary SDK, and returns the Cloudinary URL. Requires Poly-X admin auth. 10-second timeout on Cloudinary call. Returns 422 on upload failure with error message.

**Contract:** POST /api/admin/upload (multipart file) -> 200 { url: cloudinaryUrl } | 401 | 403 | 422 upload failed | 503 Poly-X unreachable; 10s timeout on Cloudinary call; no partial reference stored on failure

## Why

REQ-FUNC-010 requires all dashboard images to be uploaded to Cloudinary with the returned URL stored as the image reference, so admins can manage images through the dashboard without handling Cloudinary directly.

## What

A POST /api/admin/upload endpoint that accepts a multipart image file from an authenticated admin, sends it to Cloudinary with a 10-second timeout, and returns the Cloudinary URL, rejecting failed uploads with 422 and storing no partial reference.

## Scope

**In:** The POST /api/admin/upload route, multipart file parsing, Cloudinary SDK upload call with a 10s timeout, Poly-X admin auth wiring via the DC-001-03 introspection middleware, error handling for upload failures and timeouts, structured request-id logging, and automated tests.

**Out:** Does not build the Poly-X introspection middleware itself (provided by DC-001-03), does not build the admin dashboard UI that calls this endpoint, does not store the image reference in the data store (returns the URL for the caller to store), does not build Cloudinary account setup or image delivery transformations, and does not rebuild authentication or notification delivery (Poly-X provides it).

## Acceptance

- Given an authenticated admin submitting an image through the dashboard, When the image is uploaded, Then the system sends the image to Cloudinary and stores the returned Cloudinary URL as the image reference in the data store
- Given an authenticated admin submitting an image and the Cloudinary upload fails, When the system receives an error response from Cloudinary, Then the system rejects the submission with an error message indicating the upload failed and does not store a partial image reference
