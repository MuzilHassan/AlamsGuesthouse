# DC-002-05 — GalleryImage table

Prisma schema for GalleryImage table storing gallery images with caption, alt text, and display position.

**Contract:** GalleryImage { id UUID PK, cloudinary_url text not null, caption text, alt_text text, display_position int not null }

## Why

REQ-FUNC-020 and REQ-NFUNC-006 require gallery images with captions and alt text to persist across restarts and deployments so the gallery section remains populated and accessible without data loss.

## What

A GalleryImage table in PostgreSQL 16 defined via a Prisma 6 schema with migration and rollback, storing Cloudinary URLs, captions, alt text, and display positions.

## Scope

**In:** The Prisma model and migration for the GalleryImage table only: columns id (UUID PK), cloudinary_url (text not null), caption (text), alt_text (text), display_position (int not null).

**Out:** HeroImage, RoomImage, and other image tables; the Prisma client configuration (DC-002-07); any image upload or Cloudinary integration; API endpoints that serve gallery images.

## Tasks

- [ ] **T1** — Add the GalleryImage model to prisma/schema.prisma with id as @id @db.Uuid, cloudinary_url as String not null, caption as String?, alt_text as String?, display_position as Int not null _(verify: prisma validate succeeds and the GalleryImage model matches the contract fields and types exactly, with caption and alt_text nullable)_
- [ ] **T2** — Generate the Prisma migration for the GalleryImage table (prisma migrate dev --name add_gallery_image_table) and verify the up SQL creates the gallery_image table with all contract columns _(verify: the migration SQL creates gallery_image with id uuid PK default gen_random_uuid(), cloudinary_url text not null, caption text, alt_text text, display_position int not null)_
- [ ] **T3** — Write the down migration that drops the gallery_image table, so the migration is reversible _(verify: running the down migration removes the gallery_image table cleanly)_
- [ ] **T4** — Write a unit test that inserts a GalleryImage record with caption and alt_text, simulates a restart by re-instantiating the PrismaClient, and reads the record back to confirm it is present and unchanged; also test inserting with null caption and alt_text _(verify: the test inserts a gallery_image with caption 'Pool View' and alt_text 'Hotel pool at sunset', re-instantiates the client, reads the record and confirms all fields match; a second insert with null caption and alt_text succeeds and reads back null; TC-031 is demonstrated)_
- [ ] **T5** — Definition of Done: run prisma validate, apply the migration and its rollback, and run the persistence test suite for GalleryImage _(verify: prisma validate passes, the gallery_image migration applies and rolls back without error, the persistence test passes confirming gallery image content survives a simulated restart, and the schema is committed)_

## Acceptance

- Given managed content stored in the data store, When the application is restarted or redeployed, Then the managed content remains available in the data store unchanged
- Given managed content in the data store, When the application undergoes a restart or deployment, Then an inspection of the data store shows all managed content present and unchanged
