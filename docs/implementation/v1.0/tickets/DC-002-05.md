# DC-002-05 — GalleryImage table

Prisma schema for GalleryImage table storing gallery images with caption, alt text, and display position.

**Contract:** GalleryImage { id UUID PK, cloudinary_url text not null, caption text, alt_text text, display_position int not null }

## Why

REQ-FUNC-020 and REQ-NFUNC-006 require gallery images to persist across restarts and deployments; the GalleryImage table stores gallery images with caption, alt text, and display position for accessibility and ordering.

## What

A Prisma model and PostgreSQL migration for the GalleryImage table with id (UUID PK), cloudinary_url (text not null), caption (text), alt_text (text), and display_position (int not null), plus its rollback migration.

## Scope

**In:** The GalleryImage Prisma model definition and its up/down SQL migration only.

**Out:** Room, RoomImage, Promotion, HeroImage, and BlogPost tables; the Prisma client generation and DATABASE_URL configuration (DC-002-07); any image upload or Cloudinary integration logic; any API endpoints that read or write gallery images.

## Tasks

- [ ] **T1** — Add the GalleryImage model to prisma/schema.prisma with id as UUID @id @default(uuid()), cloudinary_url as non-null String, caption as nullable String, alt_text as nullable String, and display_position as non-null Int _(verify: prisma validate succeeds; the GalleryImage model has id UUID PK, cloudinary_url text not null, caption text, alt_text text, display_position int not null)_
- [ ] **T2** — Generate and apply the Prisma migration for the GalleryImage table with npx prisma migrate dev --name add_gallery_image_table, and confirm the down migration drops the GalleryImage table cleanly _(verify: the migration creates a gallery_image table with columns id, cloudinary_url, caption, alt_text, display_position matching the contract types; prisma migrate down removes the gallery_image table without errors)_
- [ ] **T3** — Write a persistence test that inserts a GalleryImage row, restarts the Prisma client connection, and re-reads the row to confirm it survives a connection cycle _(verify: after closing and reopening the Prisma client, the inserted GalleryImage row is present with cloudinary_url, caption, alt_text, and display_position unchanged, satisfying TC-031 for the GalleryImage table)_
- [ ] **T4** — Definition of Done: run prisma validate, run the migration up and down, run the persistence test, and confirm the schema is committed _(verify: prisma validate passes, migrate up creates the gallery_image table with the contract columns, migrate down removes it cleanly, the persistence test passes with no data loss across a connection restart, and the migration file is committed to the repository)_

## Acceptance

- Given managed content stored in the data store, When the application is restarted or redeployed, Then the managed content remains available in the data store unchanged
- Given managed content in the data store, When the application undergoes a restart or deployment, Then an inspection of the data store shows all managed content present and unchanged
