# DC-004-04 — PUT /api/admin/rooms/:id/price

Update a room price specifically. Validates price is positive numeric. Updates updated_at timestamp.

**Contract:** PUT /api/admin/rooms/:id/price { price } -> 200 { room } | 401 | 403 | 404 | 422 price invalid | 503

## Why

REQ-FUNC-011 requires that an authenticated admin can update a room's price specifically, so that the updated price is stored and the public site displays the new price on the next page load.

## What

PUT /api/admin/rooms/:id/price returns 200 with the updated room for a valid positive price, 422 for a non-positive or invalid price, 404 when the room does not exist, 401 for an unauthenticated caller, 403 for a missing admin role or organization mismatch, and 503 when Poly-X is unreachable.

## Scope

**In:** The PUT /api/admin/rooms/:id/price endpoint, its zod validation schema for a positive numeric price, the Prisma update that sets the price and updates updated_at, and the 200 response with the updated room.

**Out:** General room editing (DC-004-02); creating or deleting rooms (DC-004-01, DC-004-03); the admin UI price field (DC-004-05); authentication and authorization, provided by Poly-X via DC-001-03; the Prisma schema, provided by DC-002-07.
