# DC-008-01 — POST /api/admin/blog-posts

Create a blog post. Validates title non-blank and body non-blank with zod. Stores in PostgreSQL with is_published default false.

**Contract:** POST /api/admin/blog-posts { title, body, imageUrl? } -> 201 { blogPost } | 401 | 403 | 422 title or body blank | 503

## Why

Admins need to create blog posts with a title, body, and optional image so that content can be managed through the dashboard and displayed to guests, satisfying REQ-FUNC-022.

## What

A POST /api/admin/blog-posts endpoint that validates title and body as non-blank with zod, stores the post in PostgreSQL with is_published defaulting to false, and returns the created blogPost object with a 201 status.

## Scope

**In:** The POST /api/admin/blog-posts route handler, zod validation schema for title and body, Prisma create call for the blog_posts table, and the 201/401/403/422/503 response shapes.

**Out:** Editing, publishing, or deleting blog posts (DC-008-02, DC-008-03, DC-008-04); the admin UI forms (DC-008-05); the blog_posts Prisma model definition itself (DC-002-07); authentication and authorization logic (DC-001-03 provides Poly-X introspection); image upload handling (DC-003-01 provides the upload endpoint).
