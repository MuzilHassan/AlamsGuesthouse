# DC-007-01 — POST /api/admin/gallery

Add a gallery image. Accepts Cloudinary URL, caption, alt text, and display position.

**Contract:** POST /api/admin/gallery { cloudinaryUrl, caption?, altText?, displayPosition } -> 201 { galleryImage } | 401 | 403 | 422 | 503

## Why

REQ-FUNC-016 requires that an admin can add gallery images with caption and alt text through the dashboard, so the system can store and display curated images on the public site.

## What

A POST /api/admin/gallery endpoint that accepts a Cloudinary URL, optional caption, optional alt text, and display position, stores the gallery image record, and returns 201 with the created object.

## Scope

**In:** The POST /api/admin/gallery route handler, request body validation, Prisma create call for the gallery image record, Poly-X introspection and admin role authorization, and error responses (401, 403, 422, 503).

**Out:** The Prisma schema and GalleryImage model definition (provided by DC-002-07), the Poly-X SDK installation and introspection middleware implementation (provided by DC-001-03), the image upload endpoint (provided by DC-003-01), the gallery management UI (DC-007-04), and the PUT and DELETE endpoints (DC-007-02, DC-007-03).
