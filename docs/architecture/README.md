# Architecture

Alara Code writes this folder: the approved SRS, technical architecture (TAD), software design (SDS) and API contract of every pipeline version, one file per document per pipeline version (named after the version, for example `srs-v1.0.md`). Files in it are never overwritten or deleted. The index in the parent folder lists every file and which one is current.
