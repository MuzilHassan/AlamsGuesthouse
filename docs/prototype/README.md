# Prototype

Alara Code writes this folder: the approved UI prototype of every pipeline version, and the design file it was built on, one file per document per pipeline version (named after the version, for example `prototype-v1.0.html`). Files in it are never deleted, and the prototype itself is never overwritten; the design file of a version (`design-v1.0.md`) is the one file that is replaced, when the prototype is run again in that version. The index in the parent folder lists every file and which one is current.
